Import Recipe from JSON

Paste the JSON-LD data for a recipe below. You can use structured ingredients (with name, quantity, measurement) or simple strings.

Example JSON Structure

{
  "@context": "https://schema.org/",
  "@type": "Recipe",
  "name": "Sample Recipe Title",
  "recipeIngredient": [
    { "name": "all-purpose flour", "quantity": "1", "measurement": "cup" },
    { "name": "large eggs", "quantity": "2", "measurement": "" },
    { "name": "salt", "quantity": "0.5", "measurement": "tsp" }
  ],
  "recipeInstructions": [
    { "@type": "HowToStep", "text": "First step description." },
    { "@type": "HowToStep", "text": "Second step description." }
  ],
  "keywords": "sample, example, easy"
}
