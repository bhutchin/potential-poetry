Import Recipe from JSON

Paste the JSON-LD data for a recipe below. This is a structured data format used by many modern recipe websites.

Example JSON Structure

{
  "@context": "https://schema.org/",
  "@type": "Recipe",
  "name": "Sample Recipe Title",
  "recipeIngredient": [
    "1 cup flour",
    "2 large eggs",
    "1/2 tsp salt"
  ],
  "recipeInstructions": [
    { "@type": "HowToStep", "text": "First step description." },
    { "@type": "HowToStep", "text": "Second step description." }
  ],
  "keywords": "sample, example, easy"
}
